# PlagiScan UI Upgrade (v2)

Detection engine, routes and features are unchanged. Only presentation and customer-facing wording changed.

- Removed the "How it works" 4-step section and the backend "Engine ready" badge
- Removed technical wording (TF-IDF, cosine, containment, search engine name) from customer-facing screens
- Search engine picker kept, but tucked under "Advanced options"
- Ring shows only the percentage (no "Similarity" label)
- Removed the "signal to review" disclaimer
- "Check originality" -> "Check plagiarism"; report and verdicts now say plagiarism
- New scanning screen: spinner, plain-language status, progress bar
- New visual identity: ink navy + highlighter yellow (red = matched, blue = partly similar, green = clean)
